# 奶龙.code

Windows 本地文件资料库。可自定义目录与分类关键词，初始提供学科规则。

## 首次配置

需要 Windows 10/11 和 Windows PowerShell 5.1（系统自带）。将 `config.example.json` 复制为 `config.json`，将 `inbox` 改成自己的资料目录绝对路径，例如 `D:/资料库`。请使用 UTF-8 保存 JSON，路径建议使用 `/`。本机配置不会提交到 Git。

## 使用

双击 `奶龙.code.vbs` 打开资料库。`启动监听.vbs` 开启后台分类，托盘菜单可以暂停或退出。

- 拖入普通文件：从原位置移动到资料根目录，待文件稳定后分类。同名文件自动改名。
- 拖出列表文件到桌面：由 Windows 资源管理器执行移动；也可右键“移到桌面”。
- 按 F2 或右键重命名；Ctrl / Shift 多选，Ctrl+A 全选当前搜索结果。
- 点击列标题排序。目录、修改时间、格式和关键词可组合筛选。
- 空格分隔的关键词全部匹配；英文引号匹配短语，`-关键词` 排除匹配项。
- “管理目录”新建目录或编辑文件名、正文关键词。目录名称自动成为文件名关键词。
- 预览使用 Windows 注册的系统预览器，支持 PDF 翻页、滚动及 Office 文档原有排版。没有可用组件时，PDF 使用可翻页的备用预览，文本使用滚动预览。PDF / 扫描件目前不支持正文提取或 OCR。
- 批量打印使用 Windows 默认打印机和已安装应用的打印入口。先检查清单再提交；没有打印入口的格式会跳过。提交到打印程序不代表纸张已经输出。

## 分类与重复文件

文件名与正文交叉核对；多目录命中或两者冲突时请用户选择。没有足够依据的文件不会自动猜测。

重复文档按 SHA-256 分组，并在回收前重新校验哈希、大小和逐字节内容。空文件、临时文件、内部目录、链接和占用文件均跳过。不同格式的文档只有字节内容完全相同时才算重复，同名不作为删除依据。

“查找重复”先显示预演，勾选后可送入回收站。“自动去重”默认关闭，勾选并确认后仅在资料库窗口运行期间生效；不会永久删除，也不会操作原有试卷直到用户在界面开启或确认回收。操作记录在 `_dedupe-journal.jsonl`。

## 测试

先完成上述配置，再在本目录的 Windows PowerShell 运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\run-tests.ps1
```

测试使用独立资料验证真实回收、恢复、文件变化、锁定、目录链接、索引并发、导入分类、重命名及模拟打印，不会向打印机发送任务。`-ScratchBase` 可指定另一个磁盘的隔离测试位置，以验证跨磁盘移动和该磁盘的回收站。

全部测试通过后生成 `tests\verified.json`。删除功能会检查测试结果、代码及测试脚本哈希、回收测试和磁盘；任何不匹配都会锁定删除入口。生成的索引、日志和测试资料不纳入 Git。

界面采用目录树、标准文件列表和可调整宽度的预览窗格。去重扫描、搜索和索引更新在后台独立运行；扫描可随时取消。预览组件也独立运行，退出或故障不会终止主窗口。

`tests/background-tests.ps1` 和界面集成测试使用专门的隔离资料库，要求 `inbox` 指向程序目录中的 `test-library`，不可针对日常资料目录运行。预览测试还需要自行准备有效的 PDF：`test-library/物理/PDF预览测试.pdf`；界面响应测试需要 `test-library/物理/真实PDF预览测试.pdf`。这些资料文件不会随仓库分发。核心安全测试会自行生成测试数据。
