# 奶龙.code

Windows 本地文件资料库。可自定义目录与分类关键词，初始提供学科规则。

## 首次配置

从 GitHub Releases 下载 Windows ZIP 后解压，双击 `奶龙.code.cmd`。首次启动会让你选择资料目录，程序自动从随包附带的 `config.example.json` 创建本机配置；以后启动保留原配置。需要 Windows 10/11 和系统自带的 Windows PowerShell 5.1。资料目录应在程序文件夹之外。

安装包不需要 Git。源码仓库位于 GitHub，安装目录与源码检出目录各有用途；ZIP 中没有 `.git` 属于正常情况。每版编号见 `VERSION`，完整变更见仓库根目录 `CHANGELOG.md`。历史测试数据和升级备份不进入发布包。

也可手动复制 `config.example.json` 为 `config.json`，将 `inbox` 改成自己的绝对路径并以 UTF-8 保存。

## 使用

双击 `奶龙.code.cmd` 打开资料库并自动启动分类监听。界面“监听”按钮可暂停、恢复；“更多 → 停止分类监听”可停止，关闭应用会结束其监听。兼容的 `启动监听.vbs` 也打开同一应用入口。

运行 `tools/install-desktop.ps1` 创建桌面快捷方式，并关闭本应用已有的启动文件夹入口；不会添加开机自启动，也不会移除其他程序的启动项。

- 拖入普通文件：从原位置移动到资料根目录，待文件稳定后分类。同名文件自动改名。
- 拖出列表文件到桌面：由 Windows 资源管理器执行移动；也可右键“移到桌面”。
- 按 F2 或右键重命名；Ctrl / Shift 多选，Ctrl+A 全选当前搜索结果。
- 点击列标题排序。目录、修改时间、格式和关键词可组合筛选。
- 空格分隔的关键词全部匹配；英文引号匹配短语，`-关键词` 排除匹配项。
- “管理目录”新建目录或编辑文件名、正文关键词。目录名称自动成为文件名关键词。
- 预览使用 Windows 注册的系统预览器，支持 PDF 翻页、滚动及 Office 文档原有排版。没有可用组件时，PDF 使用可翻页的备用预览，文本使用滚动预览。可在“更多 → 识别扫描件文字”启用本机 OCR，默认识别每份 PDF 前两页以及图片；不上传文件，页数、大小与等待时间有上限。语言包缺失时保留预览与文件名搜索。
- 批量导入、移出和打印任务在后台执行，状态栏显示已处理/总数，可选择“停止后续”。当前文件完成后才停止；已经移动或提交打印的项目会保留，回收执行期间请等待完成后关闭窗口。

批量打印使用 Windows 默认打印机和已安装应用的打印入口。先检查清单再提交；没有打印入口的格式会跳过。提交到打印程序不代表纸张已经输出。

## 分类与重复文件

人工选择已有目录时，可勾选“记住文件名关键词”并调整关键词。只有文件成功移动、关键词确实来自文件名且不与其他目录规则冲突时才保存；未勾选、取消或移动失败均不学习。

配置包含 `schemaVersion`。旧配置自动补充缺省项，保留自定义字段和显式关闭选项，首次结构迁移前保存原配置备份。

文件名与正文交叉核对；多目录命中或两者冲突时请用户选择。没有足够依据的文件不会自动猜测。

重复文档按 SHA-256 分组，并在回收前重新校验哈希、大小和逐字节内容。空文件、临时文件、内部目录、链接和占用文件均跳过。不同格式的文档只有字节内容完全相同时才算重复，同名不作为删除依据。

“查找重复”先显示预演，勾选后可送入回收站。“自动去重”默认关闭，勾选并确认后仅在资料库窗口运行期间生效；不会永久删除，也不会操作原有试卷直到用户在界面开启或确认回收。操作记录在 `_dedupe-journal.jsonl`。

## 测试

在 Windows PowerShell 运行一键检查，无需准备个人资料或 PDF：

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\tools\check.ps1
```

默认执行源码语法/结构检查、隔离安全测试、后台任务和自动生成的图片/PDF 预览测试。没有交互桌面时会明确跳过前台激活和真实键盘输入断言。

本机完整验证（会短暂显示隔离测试窗口，并验证测试文件的真实回收与恢复）：

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy RemoteSigned -File .\tools\check.ps1 -Desktop -Recycle
```

测试自动在临时目录建立隔离应用和资料，运行后清理；报告保存到被 Git 排除的 `test-artifacts/latest`。源码配置与删除验证记录不会被一键检查修改，测试不向打印机发送任务。CI 使用同一入口，上传经过筛选的测试报告。

实际使用回收功能前，在应用所在目录运行 `tests/run-tests.ps1`，全部安全测试通过后生成 `tests/verified.json`。入口会核对运行代码、测试脚本哈希和真实测试磁盘；代码变化、跳过回收测试或换磁盘后均需重新验证。可通过 `-ScratchBase` 指定资料磁盘上的独立测试目录。

界面采用目录树、标准文件列表和可调整宽度的预览窗格。去重扫描、搜索、索引更新和预览在后台进程运行。

日志将正常忙锁记为 INFO，同类重复消息节流并累计次数，真实错误保留首条。跨进程日志追加与轮转使用独立锁；回收记录保留在独立审计文件。

启动策略、未签名说明与组件降级方式见 [运行环境说明](RUNTIME.md)。
